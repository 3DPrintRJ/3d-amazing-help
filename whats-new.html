Latest update

Version 0.8 Beta

September 28, 2026 · 8:09 PM CDT

0.8.0-beta.4 · Build 3f3bbe9

New

  • Added founder-only Admin · Users & Subscriptions so account, plan, beta, signup, sign-in, and Stripe-managed subscription status can be reviewed in one place.
  • Added document-level discounts to Quotes: no discount, whole-number percentage, or fixed dollar amount.

Improved

  • Quote discounts now reduce the taxable subtotal before sales tax is calculated and appear on the Quote detail, print/PDF output, email, and Reports.
  • Converting a Quote creates a Draft Invoice that inherits the Quote’s items, prices, discount, and tax settings. The Draft can still be adjusted before Finalize.
  • Invoice editing now allows the document discount to be adjusted along with eligible quantities, prices, tax selection, due date, and notes; later finalized-Invoice changes continue to be recorded as revisions.
  • The Quote record toolbar is more compact. Common actions remain visible while Void and Delete are grouped under More.
  • Full Business Backup continues to include Quote discounts, and restore supplies safe discount defaults for older compatible backups.
  • Release notes now include the release time as well as the date so multiple beta builds on the same day are easy to distinguish.
Previous update

Version 0.8 Beta

September 28, 2026 · 7:39 PM CDT

0.8.0-beta.3 · Build b4138f1

Fixed

  • Fixed a Quote-opening error that could show invalid input syntax for type uuid when opening a Quote directly from Reports or another result list.
  • Fixed document email delivery being blocked by missing server write permissions on the email-delivery audit table.
  • Fixed Quote Unit Price editing so values such as $30.00 can be typed normally without the field fighting the edit.

Improved

  • Quote editing is more compact, with a shorter Catalog picker and an optional custom-item section that stays collapsed until needed.
  • Quote Save Quote Changes / Cancel actions now stay in a sticky bottom action bar while editing.
  • Invoice revision Save Revision / Cancel actions now use the same bottom action pattern for consistency.
  • Customer-facing email errors no longer expose raw database or server implementation details.

Version 0.8 Beta

September 28, 2026 · 7:27 PM CDT

0.8.0-beta.2 · Build 5d4c565

Improved

  • Reports now preserve the exact report type, date range, filters, customer, and sort order in the page address.
  • Customer, Quote, Invoice, and Receipt results can be opened directly from Reports; desktop rows support double-click where a detail destination exists.
  • Global Search now preserves the search term and supports direct row opening for Customers, Quotes, Invoices, and Receipts.
  • Records opened from Reports, Search, or Customer history now show a context-aware Back button and return to the originating results.
  • Opening a Quote or Invoice from results opens its detail view first instead of automatically entering edit mode.

Earlier beta baseline

September 24, 2026

This entry records the major capabilities that were already present in the web beta when the Help Center documentation baseline was updated.

Sales & customer workflow

  • Customers, Catalog, Create Sale, Invoices, Payments, Reports, and Practice workflow.
  • Draft/final Invoice workflow, Quick Sale receipts, and Quotes with print/email and conversion to Invoice.
  • Customer-specific pricing, transaction history, and one-time recipients where applicable.

Catalog, inventory & costing

  • Catalog types, groups, assemblies, material and component costing, markup, and optional inventory tracking.
  • Printed-product costing for material, print time, electricity, hardware, packaging, and labor.

Documents, payments & reports

  • Email Invoice, Receipt, Quote, and Payment Receipt.
  • Full and partial payments.
  • Customer, Sales Summary, Invoice, Receipt, Payment, Outstanding Balance, Quote, and Catalog/Inventory reports.

Business settings & usability

  • Business information, regional settings, backup/restore/import tools, Plan & Support, and spreadsheet imports.
  • Persistent actionable errors and warnings, improved contrast, password visibility controls, and in-app help guidance.

About these release notes

Release notes focus on changes that affect customers. Internal development details, database maintenance, and routine technical work are omitted unless they change how the app behaves.
