Version 1.0 Alpha

September 30, 2026 · 8:34 PM CDT

1.0.0-alpha.1 · Build afcaf2c

Events and Event reporting

  • Added Events for craft shows, fairs, markets, conventions, festivals, pop-ups, and other in-person selling activity.
  • One Event can be marked Current so new Quick Sales and Invoices default to it, with confirmation before changing the Current Event.
  • If an Event includes today’s date and no Event is Current, 3D Amazing can prompt you to review or set the appropriate Current Event.
  • Quick Sales and Invoices now clearly show whether they are assigned to an Event, and completed documents retain that Event association.
  • Reports now support Event filtering, plus a dedicated Event Summary showing sales, orders, deposits, customers acquired, estimated product cost, Event expenses, and estimated Event result.

Event costs and corrections

  • Event expenses can be recorded with Expense date, Category, Amount, Description, and Notes.
  • Existing Event expenses can now be edited in place with Save Changes or Cancel, while Remove remains a separate confirmed action.
  • Event selectors now include the Event date range so repeated shows with similar names are easy to distinguish; Current and Archived indicators remain visible.
  • Completed Quick Sales and Invoices can have an incorrect Event assignment corrected, with confirmation before totals are moved to another Event.

Practice and reliability

  • Practice document email now works through the normal email/PDF workflow.
  • Practice reset now restores the additional sample Catalog groups required by the current Practice dataset instead of failing on missing groups such as Filament.
  • Event completion, archived Event history, and Current Event handling were hardened to prevent stale or cross-workspace Event state.
  • Report changes now hide stale results until Run Report is selected, preventing a previous report from being mistaken for the newly selected Event report.

Version 0.8 Beta

September 29, 2026 · 7:29 PM CDT

0.8.0-beta.10 · Build 21bc381

Payments and invoice corrections

  • Posted Invoice payments can now be voided instead of being silently edited or deleted.
  • Voiding a payment keeps the original payment in history, marks it Void, and restores the payment amount to the Invoice balance.
  • Customer Payment history now includes payment status and a Void Payment action for posted Invoice payments.
  • Quick Sale payments continue to be corrected by opening and voiding the Quick Sale receipt rather than voiding its payment separately.
  • Recording a payment against a Draft Invoice now properly finalizes the Invoice first, recording the normal Open status, finalization timestamp, and audit history before applying the payment.

Plan access during beta

  • Account access now distinguishes controlled Beta, future Free, Paid, and internal access states.
  • Approved beta testers remain unrestricted during the controlled beta and are not subject to future Free-plan usage limits.
  • Future Free-plan capacity is based on customers, Catalog products, and completed sales while keeping normal core app features available.

Version 0.8 Beta

September 29, 2026 · 4:06 PM CDT

0.8.0-beta.9 · Build c6e40f6

Flexible invoice dates and terms

  • Invoice creation now includes an editable Invoice Date, payment-term shortcuts for Due on receipt and Net 7/15/30/45/60, and an editable Due Date.
  • Payment terms calculate a suggested Due Date, but both dates remain editable for historical-entry testing or unusual business arrangements.
  • If a Due Date is earlier than the Invoice Date, the app shows a warning instead of blocking the Invoice.
  • Eligible saved Invoices can now revise Invoice Date, payment terms, and Due Date along with the existing editable fields; the revision snapshot preserves the earlier values.

Quotes and sales tax

  • New Quotes default to Valid for 7 days, with 14 days, 30 days, and Custom available. The calculated expiration date can still be overridden.
  • Tax-exempt customers no longer show a misleading checked/disabled sales-tax checkbox. The transaction now clearly states that no sales tax will be charged.
  • The lower Create Invoice area was tightened and reorganized so totals, dates, notes, and final actions read more cleanly.

Version 0.8 Beta

September 28, 2026 · 8:46 PM CDT

0.8.0-beta.5 · Build c79042c

Security hardening

  • Completed an app-wide Supabase access audit. Anonymous users no longer have direct business-table CRUD access, anonymous execution of business SECURITY DEFINER RPCs is zero, and broad PUBLIC RLS policies were removed.
  • Reduced direct signed-in access to obsolete/versioned database RPCs while preserving the current application RPC surface.
  • The founder beta-invite service now requires Supabase gateway JWT verification in addition to its founder-only authorization check.
  • Added baseline production security headers, including HSTS, clickjacking protection, MIME sniffing protection, referrer controls, and restrictive browser permissions.
  • User-chosen passwords now require at least 12 characters with uppercase, lowercase, number, and symbol, and are checked against known breached-password data using a privacy-preserving k-anonymity lookup.

Beta access

  • Self-service business creation is disabled during the controlled beta. Beta accounts are created through an invitation.
  • The sign-in and signup screens now clearly identify the current invitation-only beta.
  • Cloudflare Turnstile support is prepared for signup, sign-in, and password-reset requests before public self-service signup is enabled.
