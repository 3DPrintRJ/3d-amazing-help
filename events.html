Events

Track craft shows, markets, fairs, conventions and other in-person selling events. Each Event can include dates, location, sales activity and expenses.

Current beta documentation · Updated October 25, 2026

Event calculation guidance remains optional

The Event result explanation was already collapsible. It remains in place while Event totals, expenses, current-event status and required controls stay visible.

Shared mobile navigation

Events retains its event list, current-event assignment, expenses and reports. Only the shared mobile header and navigation change; Event workflows and expense rules remain unchanged.

Compact Events list

Event browsing now uses tighter spacing, making more Events visible without changing their dates, status or Current Event assignment. Select an Event to enter its focused details, sales and expenses view; New Event and expense editing retain the dedicated focused forms. Event results still exclude processor fees unless specifically accounted for elsewhere.

Browse Events

Open Events from the app. The Event list shows dates, status and location. Select an Event’s name or View to open its own workspace. The list is hidden while you work on that Event, so there is less scrolling and distraction.

Create or edit an Event

Select New Event, or use Edit on an existing Event. A focused form opens with Event name, venue/location, start and end dates, and optional notes. Save using Save Event or Save Changes.

Cancel leaves the form. If you have changed anything, a confirmation offers Keep Editing or Discard Changes. Nothing is discarded by merely opening the confirmation.

Review Event results

From the list, select View for an Event. The working screen displays completed sales (excluding sales tax), order/invoice counts, deposits collected during the Event, customers acquired, estimated product cost, Event expenses and the estimated Event result. Back to Events returns you to the Event list.

Use How this result is calculated for a short explanation. Orders and outstanding balances are shown separately and are not added again to completed sales. Selling and card-processing fees are not yet included.

Record Event expenses

While viewing an Event, select Add Expense to open a focused expense form. Choose the expense date, category, amount, description and optional notes, then select Add Expense. Existing expenses offer Edit and a separately confirmed Remove action. If you cancel an edited expense, you can keep editing or discard your changes.

Event expenses should only include costs incurred because you attended that particular Event; they are not a general-purpose accounting ledger.

Choose the Current Event

Select an Event name to open its details; a separate View button is no longer needed. From the Event list, select Make Current and confirm your selection. New Quick Sales and Invoices can default to the Current Event. The list also provides Clear Current, Complete, and Archive/Restore actions. Completed or archived Events remain part of Event history.

Reports and practice

Use Reports to filter reporting by Event and review the results. Practice workspace Event data stays separate from your real business workspace.

Using a phone? Select an Event to open its focused workspace. Editing takes place in a prominent panel with direct Save and Cancel actions rather than expanding below the Event list.

Compact Event lists

On phones, Events and Event Expenses appear as compact rows showing the name or category, date, amount or status, and essential details. Use Actions on a row to reveal Edit, Make Current, Complete, Archive, Restore, or expense removal as applicable. These actions retain their existing confirmations.
