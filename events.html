Events

Track craft shows, markets and other selling events.

Create an Event

  1. Open Events.
  2. Choose New Event.
  3. Enter its name, dates, location and other needed details.
  4. Save.

Make an Event current

Choose Make current for the event you are working. Confirm before switching an active event.

Record expenses

Add table fees, travel and other Event expenses to track costs alongside sales.

Review results

Open the Event or Reports for sales and expense summaries.
