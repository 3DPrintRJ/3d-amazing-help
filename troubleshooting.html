Troubleshooting

First checks for common beta problems.

Current beta documentation · Updated September 24, 2026

Update available / screen looks stale

The app rechecks for a newer build when you return to the tab. If an update is available, use Refresh app; it performs a cache-busting reload so the current deployed build is fetched.

Full Business Backup fails

Current Full Business Backup is generated through the authenticated 3D Amazing server instead of reading each database table directly from the browser. Refresh the app and retry. If it still fails, note the exact error and contact support.

Wrong or missing data

  1. Check Current area and make sure you are in the intended business or Practice.
  2. Refresh the app.
  3. Check Active/Archived, date, type, status, and other filters.
  4. Use Search to locate the record.

Cannot sign in

Confirm the email/password. Temporary beta credentials may require changing the password on first sign-in.

Archived record disappeared

Change the View filter to Archived or All, then restore the record if needed.

Cannot permanently delete

Records with protected dependencies/history cannot be permanently deleted because doing so could orphan business history.

Unexpected price

Check customer-specific pricing, Customer default discount, standard Catalog price, and any manual transaction override.

Email did not send

If the email dialog reports failure, the underlying Invoice/Receipt/Quote/Payment remains saved. Confirm the recipient address and retry from the saved document.

Email service not configured: If the app specifically says document email delivery is not configured, contact support. Do not assume a message was sent.

Offline Quick Sale will not sync

Reconnect to the internet and use the Quick Sale sync controls. If a sale reports Conflict, read the conflict message before retrying. Requested receipt email is attempted only after the sale itself syncs successfully.

An error message stays on screen

Actionable errors and warnings now remain visible until you dismiss them or a later explicit action replaces them. This is intentional so important backup, restore, import, payment, save, email, authentication, and destructive-action failures are not lost after a few seconds. Use Dismiss after you have read the message.

Still stuck?

Use Support Options.

Restore says the business is not empty

Restore All Business Data is intentionally limited to an empty real business. If you want reusable data from a backup in a populated business, return to the verified backup and choose Import Selected Data.

Restore says the backup version is unsupported

Automatic restore supports the current Full Business Backup format. If the original account still exists, export a fresh backup using the current app. Otherwise contact support rather than editing the JSON file manually.
