Business Settings

Business Settings is divided into four compact areas so occasional tools do not bury day-to-day configuration.

Current beta documentation · Updated October 25, 2026

Business Info

This is the default section. Enter business identity/contact information, regional settings, and sales/invoice defaults.

Location & regional settings

Country, selling currency, time zone, and address fields are grouped together. Country controls address labels and postal/region validation. When Country changes, 3D Amazing may suggest a matching Currency and Time zone, but intentional overrides are allowed.

United States, Canada, and Australia use controlled State/Province/Territory choices. Other supported countries use country-aware labels and postal validation where practical. The interface remains English-only.

Payment Processing

Connect the seller’s card processor once, then choose which connected processor is the default for Card payments. Card credentials remain with the processor; 3D Amazing stores only the verified payment result and processor references needed for business history.

Square

Square has separate Sandbox and Production connection paths. Sandbox is for OAuth/API setup only and cannot run Square POS-app card transactions. Production uses separate application credentials and a Production-only webhook/signing key so live seller traffic is not mixed with Sandbox testing.

Square live safety lock: Connecting a Production Square account does not by itself enable charges. Live Square payments remain disabled until the controlled real-transaction test is explicitly enabled.

Stripe

Stripe seller payments use a separate Stripe Connect seller account and supported Terminal workflow. This seller connection is separate from any Stripe subscription used to pay for 3D Amazing itself. Test-mode payments and full Stripe Quick Sale refunds have been verified.

External Card Processor

Use this fallback for another terminal or unsupported provider. Process the card outside 3D Amazing, then confirm the sale and optionally record the processor reference.

Data Tools

Open Business Settings → Data Tools and choose one of four focused tasks: Backup Workspace, Restore Workspace, Import Selected Data, or Spreadsheet Import / Export. Only the selected task appears, with an obvious Back to Data Tools action. Existing backup/import safeguards still apply. Practice has a separate Reset Practice task; export and import are unavailable in Practice.

Full Business Backup

Downloads business settings and supported Customer, Catalog, pricing, Quote, Invoice/Receipt, Payment, inventory/fulfillment, and document-email history data as JSON. The backup is generated through the authenticated 3D Amazing server. Practice export/import remains disabled.

On compatible desktop browsers you can choose and remember a local backup folder, and change it later. If folder access is unavailable, use the browser download option. The app only confirms a backup was saved after writing to the chosen desktop folder; browser downloads are reported as Download requested until you check the file yourself.

Phones and tablets

3D Amazing supports everyday mobile work, including sales, customer lookups, and supported data downloads. For backups, imports, full restores, and detailed reports, a Windows, Mac, or Linux computer is recommended when available, but supported tasks are not blocked on mobile.

Tap Download Backup. On iPhone or iPad, after accepting the browser download prompt, open Files → Recents or Downloads to check the JSON backup. On Android, use the device's Files or Downloads app. The app shows the filename directly under the backup button so you can identify it. Keep your backups in a secure location and verify the file exists.

The optional mobile-use notice can be dismissed with Got It — Don't Show Again or postponed using Remind Me Later. You can view the guidance again from Menu → Mobile Use Guide.

Mobile restore warning: Full Restore replaces current business data. On mobile, 3D Amazing recommends using a computer and asks you to confirm you want to choose a backup. The existing backup verification and required RESTORE confirmation are still enforced.

Restore Full Backup / Import Selected Data

These actions are available as separate focused tasks in Data Tools. Choose the action you want, select a current 3D Amazing JSON backup, and the app checks the file automatically before anything is changed. It then shows the business name and record counts and opens the appropriate Restore or Import options.

Restore Full Backup

Use Full Restore for disaster recovery. After you choose and verify a backup, 3D Amazing opens a focused confirmation window containing only the backup summary, replacement warning, RESTORE field, and Restore/Cancel actions. It replaces the current business data with the verified backup; the business does not need to be empty first. The restore is transactional/all-or-nothing: if the restore fails, the current business data is kept.

3D Amazing recreates backed-up records with new internal IDs where needed and remaps linked Customers, Catalog items, Invoices, Payments, Quotes, fulfillment, inventory, and other supported relationships.

Account and billing state are preserved, not restored from the backup. Authentication credentials, plan tier, Stripe customer/subscription IDs, billing status, and other account-security fields stay attached to the current account/business. Restoring data into an existing Paid business therefore keeps that Paid relationship.

Import Selected Data

Use Import Selected Data when the current business already contains records and you want reusable data from a backup. The initial safe import choices are Customers, Catalog items/Categories/costing/components, and customer-specific pricing.

The import preview shows new versus matching Customers and Catalog items. Matching records are preserved and skipped rather than overwritten. Existing customer-pricing pairs are also skipped.

Historical transactions are not merged into a populated business. Selected-data import does not import Invoices, Receipts, Payments, inventory movements, fulfillment history, or document-email history.

Spreadsheet import

Customer and Catalog imports validate the expected spreadsheet type before inserting records. A Product sheet cannot be imported as Customers and vice versa. Invalid rows are reported instead of being silently turned into generic records.

Catalog imports also create any explicitly supplied Group names in the managed Group list before inserting the items, so imported groups remain controlled after import.

Plan & Support

Shows the current Free Plan or Paid Plan, customer usage/limits, subscription controls when applicable, and the support level included with the plan.

Support: Free uses self-service Help Center and in-app Help. Paid also includes direct support.

Delete Account

Delete Account appears as a compact account action. Clicking it opens the full deletion warning and confirmation instead of permanently occupying the Settings screen.

The modal explains backup/restore, Stripe cancellation, and permanent deletion. Type DELETE to confirm. If Stripe manages an active subscription, 3D Amazing cancels recurring billing before deleting the owned business, Practice, and login.

Back up and verify your data before deleting your account. The deleted account itself cannot be recovered. A valid Full Business Backup can restore business records into a newly created business later, but Stripe subscription/billing state is not recreated from the backup. Account deletion does not automatically create a refund for previously paid subscription time.

If an owned business ever has other members, account deletion is blocked until ownership is transferred or the other members are removed so shared business data cannot be erased accidentally.

Save

Business Info changes are saved through Save Business Settings. Automatic recovery protects in-progress settings changes from stale overwrites. After a successful Full Restore, the app shows a completion result before deliberately reloading the restored business, so old Settings state does not trigger a false unsaved-changes warning.
