Founder administration

Users & Subscriptions

This page is available only to the 3D Amazing founder account. It combines authentication, plan, beta, and subscription information so account activity can be reviewed without cross-referencing Supabase and Stripe manually.

Founder-only documentation · Updated September 29, 2026

Summary cards

The top cards show Total Users, Free, Paid Plan, Active Subscribers, Beta Users, and Never Signed In. Select a card to filter the user table.

Paid Plan versus Active Subscriber: Paid Plan means the business currently has paid access. Active Subscriber specifically means a live Stripe-managed subscription. Founder/test access can therefore appear as Paid without being counted as an active Stripe subscription.

User table

Review the account email, business name, plan, subscription status, beta status, signup date, last sign-in, and renewal/end date. A user who still has the temporary beta password requirement is also identified.

Search and filters

Search by email, business, plan, or subscription status. Filters are available for all users, Free, Paid, Active Subscribers, Beta Users, and users who have never signed in.

Security

The Admin menu is hidden for normal users, and the server independently verifies founder authorization before returning authentication or subscription data. Navigating directly to the Admin address does not grant access.

Document email status

The Admin page also checks whether the production document-email sender is configured, whether the email provider can be reached, whether the sender domain is verified, and whether recent document-email attempts exist. This makes it clear whether Email is ready before relying on it with beta customers.

Current scope

The Admin page is read-only. It is intended for monitoring users, subscriptions, and system email readiness, not changing passwords, plans, or billing records.
