Search

Global Search helps find records without first opening the module that owns them.

Current beta documentation · Updated September 23, 2026

What Search can find

  • Customers by name, business, email, or phone
  • Catalog items by identifying details such as name/SKU and supported descriptive fields
  • Quotes
  • Invoices and Receipts by document number/customer

Opening results

Select a result to open the exact record, not merely the module list. Cross-module navigation preserves context where supported.

Search examples

Try a customer name, SKU, product/material term, invoice number, receipt number, Quote number, or a business-relevant amount such as 24.00.

Search the Help Center

On the Help Center home page, type a topic such as invoice or payment. Results update as you type, with a result count and highlighted matches. Use the × button to clear the search and browse all topics.

In the app, Global Search shows its total result count beside the search field. Use Clear search to start again.
