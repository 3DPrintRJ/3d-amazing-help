Search

Global Search helps find records without first opening the module that owns them.

Current beta documentation · Updated September 28, 2026

What Search can find

  • Customers by name, business, email, or phone
  • Catalog items by identifying details such as name/SKU and supported descriptive fields
  • Quotes
  • Invoices and Receipts by document number/customer

Opening results

Customer, Quote, Invoice, and Receipt matches open the exact record, not merely the module list. On desktop, double-click a supported result row or select its linked name/number. The record opens in normal detail view; choose its Edit action only if you intend to change it.

Back to Search: Your search term is kept in the page address. When you open a supported record from Search, use Back to Search to return to the same results.

Catalog matches continue to open the Catalog item editor because Catalog is currently an editor-based workflow.

Search examples

Try a customer name, SKU, product/material term, invoice number, receipt number, Quote number, or a business-relevant amount such as 24.00.
