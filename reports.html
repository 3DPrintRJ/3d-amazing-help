Reports

Review sales and payment activity for a selected date range and print or save the result as PDF.

Current beta documentation · Updated September 2026

Report types

ReportShows
Sales SummarySummary metrics, sales documents, and payments.
InvoicesInvoices in the selected range.
Quick Sales / ReceiptsReceipt transactions.
PaymentsPayment activity.
Outstanding BalancesNon-void invoices with money still owed.

Filters

Filter by customer, status where applicable, date range, and sort order. Choose Run Report after changing criteria.

Summary metrics

The Sales Summary includes Total Sales, Payments Received, and Outstanding Balance.

Print / Save PDF

Use Print / Save PDF and choose a PDF destination in the browser print dialog.

Current beta: PDF output uses the browser print system.
