Reports

Review business activity for selected filters/date ranges and print/save supported reports.

Current beta documentation · Updated October 16, 2026

Report controls and explanation remain collapsible

How reports work and Report options were already using expandable sections. No added collapse of tax limitations, applied scope, Run Report, or printing/export actions is intended in this release.

Choose one report, then review its results

Reports now opens with ten choices: Sales Summary, Invoices, Quick Sales, Payments, Outstanding Balances, Quotes, Customers, Event Summary, Catalog & Inventory, and Sales Tax. Selecting a report opens a focused results view with All Reports to return. Reports automatically apply the current date range except Event Summary, where you must select an Event. Use Report options to change customer, Event, dates, status, sort or inventory view, then Run Report. The active report scope always shows which settings produced the displayed data. Printing and CSV exports use the applied result, never unsaved filter changes.

Date range presets

Under Report options → Date range, choose Today, Last 7 days (including today), Last 30 days (including today), This Quarter (the complete current calendar quarter, including its future end date), Last Quarter (the complete previous calendar quarter), This Year (January 1 through December 31 of the current year), Last Year (the complete previous calendar year), All Time (from the earliest invoice, Quick Sale, or recorded payment in the active business through today), or Custom dates to enter Start date and End date. Preset dates use the business time zone. Select Run Report to apply the newly chosen range; prints and exports continue to use the last applied report until then. Event Summary instead uses the chosen Event’s full date range.

Presentation update: The preview uses compact summary rows, document-style section rules, and horizontally scrollable tables on small screens rather than stacking every table cell into a tall card. Browser print headers and footers are controlled by the browser print settings, not by the app.

Focused report preview

Choose report filters and select Run Report to open a focused, scrollable preview showing the applied date range beside the report results. Use Save PDF to print or save the finished report, Email to open a prepared message in your email application (attach the saved PDF yourself), or Close to return to the report controls. Email does not automatically send or attach a PDF.

Printing a report

Select Run Report before Save PDF. Printed reports use a business-document layout with a title, the applied date range and filters, clearly separated report sections, and readable tables. For ranges without matching activity, the PDF still identifies the report and selected period. In your browser’s print dialog, you may disable browser-added headers and footers to remove the page URL and print date. This does not alter report data.

Report picker and focused results

The initial Reports screen is only a list of report types; filters and results stay out of the way until you choose a report. Once selected, the focused view shows the report name, last applied scope, Report options, Run Report, Print/Save PDF and any relevant CSV exports. Choose All Reports to switch report types. For Event Summary, choose an Event in Report options before running the report; for other types the current date range is initially applied automatically.

Filters

Available filters change with the report type. Use customer/status/date/sort controls as applicable, then choose Run Report.

Open a result

Report results link back to the underlying record. On desktop, double-click a Customer, Quote, Invoice, Receipt, or related Invoice row to open it; you can also select the linked record number/name. Opening a result starts in the normal detail view rather than automatically entering edit mode.

Return to the same report: When you open a record from Reports, 3D Amazing remembers the report type, date range, filters, customer, and sort order. Use Back to Reports on the record to return to that same report.

Business dates and currency

Report date defaults follow the business timezone, and monetary values use the business selling currency.

Save PDF and CSV

Use browser Save PDF for printable output. Customer CSV export is available in the Customer report. For Sales Tax, use Export Tax Documents CSV for one row per Invoice/Receipt, including zero-tax or tax-exempt sales, or Export Tax Components CSV for an itemized tax amount per saved component.

Understanding sales tax exports

Tax reports are based on the document date and the stored tax snapshot. They include finalized Open or Paid documents, even when an invoice is not yet paid. Draft and Void documents are not included. The exported document-level totals are not repeated once per tax component, avoiding duplicate sums.

These exports do not calculate tax collected, refunded, remitted, or filed. A refund may occur in a different reporting period; confirm the dates and amounts with your accountant. Square POS app payments initiated from 3D Amazing may be sent as a single gross amount, so Square may not show those amounts as itemized sales tax. Do not add Square tax again to a tax-inclusive 3D Amazing charge.

Use Run Report after changing dates, customer, Event, or status. If the results cannot load every matching document, the app warns you and disables CSV export until you select a shorter range. The CSV uses your business currency and can be opened in spreadsheet software.

Consistent printed documents

Reports, invoices, quotes and receipts now use aligned print typography, document headings, table treatments and page-break rules. Use Save PDF to print or save through the browser. For a PDF without the browser-added URL, date or page header/footer, disable browser headers and footers in print settings when supported. A separately generated downloadable PDF and automatic report email attachment are not part of this formatting change.

Report print layout: Print uses letter paper with wider margins and allows the report to take only as many pages as its contents require. For the cleanest PDF, turn off browser headers and footers in print settings. An otherwise empty page is not expected; report it if it recurs.

Choosing a report: Select a report tile to open its options first. Set the date range, customer, event, status, and other available filters, then select Run Report to load the preview. Choosing a tile alone does not run the report.

All Time dates: This preset finds the earliest recorded invoice or payment in the active business, and ends on the current business date. Report generation is unavailable while that date lookup is in progress. Check the displayed report date range after selecting the preset.

Email Report PDF: After running a report, select Email Report PDF, enter the recipient address and select Send Report PDF. 3D Amazing generates a report PDF attachment and sends it through the same Resend provider used for invoices and quotes. The confirmation indicates the provider accepted the message, not that the recipient opened it. Emailing a report includes the currently displayed report content, so verify the filters and recipient before sending.

Report readability: On a narrow screen, wide report tables scroll horizontally so column labels and values do not get squeezed into unreadable fragments. Emailed report attachments use labeled data rows and standardized report typography; email attachments and browser Save PDF are different rendering paths.

Printed report appearance: The print version uses a plain financial-statement layout rather than summary cards. Browser-added page addresses and timestamps are controlled by your browser’s print settings; turn off Headers and Footers to omit them.

Compact printed Sales Summary: Financial amounts print as one-line totals, with shorter section headings and less vertical space. The layout is intended to keep a small report on one page where the contents fit.

Report screen and print: Report previews now use compact, right-aligned summary totals and shorter section headings, including on mobile. Wide tables scroll horizontally on small screens. Printing uses the separate compact statement layout, and all report types share these presentation styles.

Focused on-screen records: Report sections show totals and a View records action. Open a section to see up to 10 records at a time, using Previous and Next for additional rows. These controls affect only the on-screen display: printed reports and emailed PDF reports still include every matching record.

First-time printing: The Reports screen explains browser headers and footers before the first Save PDF action. Disabling them removes the page URL and date, but also removes browser-generated page numbers. Where supported, table column headings repeat on printed continuation pages. For complete control over page numbers without browser metadata, use a dedicated generated PDF workflow.

PDF download and printing: Save PDF now downloads a report PDF with its own Page X of Y numbers and repeated column headings on continued pages. Open the file to print. The PDF does not include the application URL. Disable any optional extra print headers and footers in the PDF viewer if necessary. The emailed PDF is a separate attachment workflow.

Generated PDF table spacing: Report PDFs keep column headings on continuation pages and use extra clearance around table rules so separators do not cross the transaction text.

PDF transaction separators: Printed report table lines are positioned below each transaction row, with enough clearance to avoid crossing text, including rows with wrapped customer or Event names.

PDF formatting: Save PDF generates a report with compact Summary totals, content-aware table column widths, customer and event space prioritized over short labels, right-aligned amounts, repeated continuation headers, and Page X of Y. Open the downloaded PDF to print it.

PDF presentation: Generated reports place the reporting date range at the upper right, use compact alternating gray/white transaction rows instead of row separator lines, repeat headings after page breaks, and put Summary totals after the transaction sections. Page numbering remains at the bottom.

Report PDF tables: Generated PDF transaction cells stay on a single line. Long labels are shortened with an ellipsis; Customer has extra width and Event has less. Each transaction section includes a monetary subtotal where applicable, and the overall Summary totals remain at the end. The display truncation does not change stored customer, invoice or Event data.

Report table bands: Alternating shading covers the full height of each PDF table row, with text vertically centered and consistent padding. The same rendering applies to all generated report types and continuation pages.
