Reports

Review sales, customer, payment and Catalog activity.

Run a report

  1. Open Reports.
  2. Choose a report.
  3. Select a date range and any filters.
  4. Select Run Report, then review the results.

Open a record

Where available, select a row to open the related Invoice, Quote or other record.

Print or export

Use supported Print / Save PDF or CSV options. Available exports depend on the report.

Taxes

Report totals reflect recorded sales and tax information. Check source records before using exports for tax filing.
