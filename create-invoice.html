Create Invoice

Build a customer invoice and save it first as a Draft.

Current beta documentation · Updated September 29, 2026

Customer and items

Select an existing customer or add one inline. In the Catalog picker, every selected item starts at Qty 1; change the quantity beside any selected item before choosing Add Selected. There is no separate single-item quantity workflow. You can still adjust Quantity or Unit Price again in the Current Invoice review, remove unwanted lines, set the Due Date, add Notes, and verify the running total.

Pricing

Automatic pricing order is customer-specific price → customer discount → standard Catalog price. A manual unit-price override affects this transaction only.

Automatic recovery

Customer, items, quantities, prices, and notes are saved automatically while you work. If a newer copy exists in another tab or device, the older copy is prevented from overwriting it.

Create the Draft

When the invoice is ready, choose Create Draft Invoice. From Create Sale, open View Invoices & Receipts to finalize it, revise it later when allowed, record payments, print/save PDF, or email it.

Email after creation

Saved Invoices can be emailed directly from 3D Amazing. The Customer email is prefilled when available, but a one-time recipient address can be used without changing the Customer record.

Cancel / discard: If meaningful work exists, the app asks before discarding it. If nothing has been entered, Cancel leaves immediately.
