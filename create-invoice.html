Create Invoice

Build a customer invoice and save it first as a Draft.

Current beta documentation · Updated September 2026

Build in any order

Choose the customer first or add items first. A customer is required before creating the draft.

Add a customer

Use + Add New Customer to create and select a customer inline.

Add items

Add an active catalog product and quantity, create a reusable catalog product inline, or add a one-off custom item that exists only on this invoice.

Pricing

Automatic order: customer-specific price → customer discount → standard price. Products disabled for the selected customer cannot be added.

Manual override

Edit Unit Price directly. Use Use automatic price to restore automatic pricing.

Create draft

Add optional notes and choose Create Draft Invoice.

Clear Invoice discards the selected customer, items, notes, and unsaved inline entry.
